# الصفان الخامس والسادس — مراجعة بنية الاختبارات الرسمية

**المراجع:** SAH English Grades 5–10، سبتمبر 2026، مواصفات امتحانات الفصل الأول للصفين الخامس والسادس؛ وورقتا الفصل الأول 2025–2026 باعتبارهما أمثلة لشكل العرض لا كمصدر للأسئلة.

## المحتوى
- 4 نماذج أصلية A–D لكل صف؛ كل نموذج 8 أنشطة و40 درجة و90 دقيقة.
- Listening 1: خمسة حوارات 40–50 كلمة، وست صور بينها صورة زائدة؛ Matching، خمسة درجات.
- Listening 2: الصف الخامس حوار 100–125 كلمة، والسادس مقابلة 125–150 كلمة، خمسة أسئلة اختيار ثلاثي.
- Vocabulary: الخامس مطابقة خمس صور بست كلمات؛ السادس كتابة الكلمات من خمس صور.
- Grammar: خمس جمل، فراغ مع خيارين.
- Reading 1: الخامس خمس مقتطفات 15–20 كلمة لكل واحد مع صور؛ السادس ثلاثة نصوص 45–50 كلمة ومطابقة خمسة عبارات.
- Reading 2: الخامس قصة 100–125 كلمة، والسادس رسالة تفاعلية 125–150 كلمة، خمسة عبارات صح/خطأ.
- Writing: الخامس وصف + بريد إلكتروني (40 كلمة لكل مهمة)؛ السادس قصة من ثلاث صور + مراجعة قصيرة (50 كلمة لكل مهمة).
- 16 تسجيل MP3 اصطناعي تجريبي، مع النصوص داخل activities.json؛ تحتاج مراجعة طبيعية نهائية من حيث الصوت واللهجة.
- 33 رسمة SVG أصلية خطية بالأبيض والأسود للطباعة والتدريب.
- HTML واحد يعمل دون إنترنت عند فك ضغط كامل المجلد. التدريب الفردي بلا مؤقت والاختبارات الكاملة بمؤقت.
