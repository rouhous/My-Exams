# My Exams | اختباراتي

تطبيق مستقل للتدريب على اختبارات اللغة الإنجليزية للصفوف 5–12 وفق بنية اختبارات وزارة التعليم في سلطنة عمان.

## Project status
This repository is being prepared for the exam application release. The full reviewed bundle, including graded exam models and offline image/audio media, must be imported from the release ZIP before the student version can be considered usable.

- Grades 5–12, with Core/Elective streams where applicable
- Unit-based models and comprehensive randomized models
- Exam timed mode and individual untimed practice
- Ministry-style listening with black-and-white illustrations
- Offline media download support (upon deployment of full assets)

**IMPORTANT:** The natural audio recordings are not fully available as local MP3 assets yet. Existing local audio assets are provisional. Do not share this repository with students as a final product until tests and offline media verification pass.
